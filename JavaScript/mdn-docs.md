# Searching MDN (Mozilla Developer Network)

MDN is a documentation source for JavaScript, HTML, CSS, and Web APIs.

## Use Google with:

```text
site:developer.mozilla.org <topic>
```

Examples:

```text
site:developer.mozilla.org javascript forEach
```

---

## Search Directly on MDN

Go to:

```text
https://developer.mozilla.org
```

Use the search bar at the top.

---

## Tip

Search the exact method name:

```text
Array.prototype.reduce
```

instead of:

```text
reduce javascript
```
